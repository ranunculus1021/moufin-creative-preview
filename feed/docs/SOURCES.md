# 교육 콘텐츠의 확인 근거 · 2026-09-30

P03의 핵심은 ‘한 주 가격만으로 회사의 시가총액을 알 수 없다’다. [미국 SEC Investor.gov의 시가총액 용어 설명](https://www.investor.gov/introduction-investing/investing-basics/glossary/market-capitalization)은 현재 주가에 outstanding shares 수를 곱해 시가총액을 정의한다. [FINRA의 교육 자료](https://www.finra.org/investors/insights/market-cap)도 주식 수와 가격의 곱을 설명한다. 게시물의 A/B 가격·주식 수는 계산을 보여주기 위한 가상 숫자다. 한국 상장 종목의 실제 시가총액과 상장주식 수는 [한국거래소 KRX 정보데이터시스템](https://data.krx.co.kr/contents/MDC/EASY/main/MDCEASY003.jsp)에서 기준일을 확인해야 한다.

P08의 `PER = 현재 주가 ÷ 주당순이익(EPS)`은 [미국 SEC Investor.gov의 PER 용어 설명](https://www.investor.gov/introduction-investing/investing-basics/glossary/price-earnings-pe-ratio)과 대조했다. 그 페이지는 과거 또는 다른 기업과 비교하는 맥락을 제시한다. EPS가 0 이하인 경우 단순한 양의 배수로 해석하기 어렵다는 문장은 기본식의 분모 조건에서 도출한 설명이다. 어느 종목의 실제 PER나 적정 주가를 주장하지 않는다.

P06의 골든크로스 정의와 문제 구성은 [현재 머핀 공개 랜딩](https://stockedu-nine.vercel.app/)의 문제풀이 시안에서 확인한 흐름에 맞췄다. 이미지의 두 선은 실제 가격·수익 데이터가 아닌 설명용 가상 도식이다. ‘교차가 상승을 보장하지 않는다’는 한계를 함께 명시했다.

나머지 공감·학습 습관·서비스 소개 문구는 시장 조사 결과로 입증된 사용자 비율이나 학습 효과를 주장하지 않는다. 실제 댓글·저장·전환은 게시 후에만 관찰할 수 있다.


## v2 골든크로스 설명 보완

[미래에셋증권 KAIROS 공식 도움말](https://securities.miraeasset.com/kairos/0544.htm)의 ‘이평 골든크로스(20,60)’를 기간 조합 예시의 근거로 확인했다. [Fidelity의 단순이동평균 설명](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/sma)에 따라 각 선을 최근 20거래일·60거래일 종가의 평균으로 설명한다. [StockCharts의 골든크로스 설명](https://chartschool.stockcharts.com/table-of-contents/trading-strategies-and-models/trading-strategies/moving-average-trading-strategies/trading-using-the-golden-cross)은 기간이 짧은 이동평균선이 더 긴 기간의 이동평균선을 위로 교차하는 의미를 뒷받침한다. 20·60일은 이 카드의 예시이며 보편적으로 유일한 조합이라는 뜻이 아니다. 이미지의 선은 실제 가격에서 계산한 시계열이 아닌 가상 개념 도식이다.
