# 업로드 파일 선택

- 카드뉴스: carousel-square의 C01~C04 4장을 번호순으로 사용.
- 세로 카드뉴스: carousel-portrait의 4장을 지원되는 배치 또는 유기적 게시에서 사용. 정사각형과 섞지 않음.
- 단일 피드 광고: feed의 AD01~AD05 중 하나를 선택.
- 스토리: 같은 광고 번호의 story 파일을 선택.
- 메신저·커뮤니티 첨부: share/MOUFIN_SHARE.png.

COPY.md에서 같은 번호의 본문·제목·CTA를, LINKS.md에서 해당 매체의 URL을 복사한다. AD_DRAFTS.csv는 이 내용을 한 번에 검토하는 운영용 파일이며 광고 관리자 자동 가져오기 호환을 보장하지 않는다.

첫 비교 후보는 AD01과 AD02. 카드뉴스는 자동 재정렬 기능이 보이면 해제하고, 배치별 자르기와 실제 CTA를 미리 확인한다. 이미지 속 버튼은 그림이다. 스토리 유기적 게시에는 링크 스티커를, 피드 유기적 게시에는 실제 프로필 링크를 연결한다.

이미지의 CTA는 공개 체험 페이지로 연결한다. 전체 앱의 출시나 무료 이용을 약속하지 않는다. 출시 준비 중인 학습 앱 광고 초안이다. 공개 페이지의 과거 출시 예정일·출처 미확인 대기자 수를 먼저 정리하고, 신청 저장과 전환 측정을 확인한 뒤 유료 집행한다. 게시·발송·광고비 집행은 아직 하지 않았다.
